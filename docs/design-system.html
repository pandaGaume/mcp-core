01, Principles

Designed for developers reading carefully

Four rules that decide the rest. Each shows up as a concrete constraint in the tokens.

Monospace leads

Identifiers, commands, paths, and the package name itself are typeset in mono. Sans-serif is for prose only.

Cyan is reserved

One accent. Used for status, links, the “this package” column, and code identifiers, never decoration.

Lines, not cards

Sections separate with 1px rules. Cards appear only when content is genuinely grouped, tables, code blocks, swatches.

One column, 860 px

Long reading line. Tables and code can break this only when content requires it; nothing else does.

05, Syntax highlighting

TypeScript palette

Hand-rolled, Tokyo-Night-adjacent. Function names borrow the brand cyan so eye finds calls quickly; strings are lime, types are pale blue. No background per-line, no rainbow brackets.

// One layer of the stack: the Behavior.
import { McpBehavior, ToolSupport } from '@cyanmycelium/mcp-core'

export class CounterBehavior extends McpBehavior<CounterState> {
  namespace = 'counter'
  version   = 1

  tools() {
    return [{
      name: 'counter_increment',
      description: 'Add N to counter.',
      handler: (args, adapter) => adapter.increment(args.by ?? 1),
    }]
  }
}

08, Voice

Direct, technical, no marketing

Do

  • State the constraint, then the solution. “The official SDK is not enough when…”
  • Use the real names of types and methods inline (McpGrammarStore.toJSON()).
  • Quantify when possible, Node 20.11+, 6 grammar tools, 4 layers.
  • Show a code example before explaining what the code does.
  • End sections on a concrete consequence (“No error spam.”).

Don’t

  • “Powerful”, “seamless”, “robust”, “enterprise-grade”.
  • Decorative metaphors, hand-drawn illustrations, laptop mockups.
  • Emoji, exclamation marks, or rhetorical questions.
  • Marketing CTAs (“Get started today!”): the install command is the CTA.
  • Wrap whole sentences in inline code; only the token belongs there.
Write as if the reader has already opened a terminal. They have.
